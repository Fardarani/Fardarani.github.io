Numerical Linear Algebra

Computational methods for matrix analysis and scientific computing

Course Description

This course presents numerical techniques for solving linear algebra problems and introduces computational methods for large-scale scientific applications.

Topics

Vector and Matrix Fundamentals, Linear Systems, Gaussian Elimination, Iterative Methods, Eigenvalue Problems, Singular Value Decomposition

Lecture Materials

Lecture notes, slides and supplementary materials for numerical linear algebra.

Computational Resources

MATLAB implementations, numerical examples and exercises.
